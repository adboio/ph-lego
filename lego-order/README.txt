MAX — GENUINE LEGO / BRICKLINK ORDERING VERSION

972 pieces, 38 part/color combinations, four colors.

ORDERING
Use max-lego-new.xml for new LEGO parts only.
Use max-lego-any-condition.xml to allow new or used LEGO parts.
Both lists contain the entire model; do not import both into the same wanted list.

1. Sign in at https://www.bricklink.com/v2/wanted/upload.page
2. Select "Upload BrickLink XML format".
3. Create a new wanted list called "Max - LEGO".
4. Open the chosen XML file in a text editor and paste its entire contents.
5. Continue to the verification screen and confirm 972 pieces / 38 entries.
6. Add the items to the list, then use Buy All to compare seller combinations.
   Review seller location, condition, shipping and totals before checkout.

The XML follows BrickLink's documented wanted-list schema, including no XML
declaration. Color IDs are Tan 2, Reddish Brown 88, Dark Brown 120, Black 11.
The model's LDraw tile ID 3069b is exported as current BrickLink catalog ID 3069.
The XML has been parsed and reconciled against the adjusted model locally;
an account upload and checkout have not been performed.

BUILDING THIS VERSION
The original GoBricks model has 869 pieces. This LEGO ordering variant contains
103 additional pieces because five Dark Brown part types were replaced with
smaller parts that occupy exactly the same spaces, with no color substitutions.
Only DARK BROWN pieces receive these replacements. Other colors stay unchanged.

Original (quantity in model)      Replacement FOR EACH original piece
3010 brick 1 x 4 (82)             Two 3004 bricks 1 x 2, end to end
3002 brick 2 x 3 (9)              One 3003 brick 2 x 2 + one 3004 brick 1 x 2
3034 plate 2 x 8 (6)              Two 3020 plates 2 x 4, end to end
3032 plate 4 x 6 (2)              Three 3020 plates 2 x 4, side by side
3036 plate 6 x 8 (1)              One 3035 plate 4 x 8 + two 3020 plates 2 x 4

Follow the original 282-step guide together with these substitutions.
The original guide's parts counts, brick seams and placement maps still describe
the GoBricks version. substitutions.csv identifies every changed placement by
original step, instance and coordinates. The accompanying max-lego.ldr and
model.json contain the actual LEGO variant. The ordering XML already includes
all replacement quantities; do not add the replacement pieces a second time.

CATALOG AUDIT (OCTOBER 2, 2026)
Every one of the final 38 part/color combinations has a LEGO element code in
BrickLink's catalog color records; see catalog-check.json for the evidence.
Dark Brown 3010 and 3002 lacked normal set/element-code evidence in the records
checked, while Dark Brown 3032, 3034 and 3036 were absent from color-image records.
Rare/nonstandard listings or wanted-list counts are not reliable sourcing for
this model's quantities, so this list uses cataloged alternatives.
Catalog existence does not establish current stock, quantities or delivered cost.
The prior BrickWith price applies only to the GoBricks version.

Digital geometry, occupied-volume equivalence for substitutions, assembly order,
insertion checks and one connected final assembly pass. The 14 support/foundation
warnings remain. Splitting parts adds seams and can change stiffness. This has
not been physically assembled, and strength/tipping have not been tested.

The brick-models skill normally exports a parts CSV and an editable LDraw model.
This dedicated supplier XML and LEGO catalog audit are additional exports.
