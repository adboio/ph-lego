Import into BrickLink

  1. Sign in and open Upload to Wanted List.
  2. Select Upload BrickLink XML format and create a new list named Max – LEGO.
  3. Open one downloaded XML file in a text editor and paste its contents into BrickLink. Use only one of the two files.
  4. Verify 976 pieces and 39 entries, add them to the list, then select Buy All to compare sellers. Check shipping and totals before checkout.

What changes from the original guide?

The original GoBricks guide has 873 pieces. This version replaces five difficult-to-source Dark Brown part types with smaller LEGO parts occupying exactly the same spaces. Colors and overall shape stay the same; the extra seams bring the total to 976.

Apply these replacements only to Dark Brown pieces. The wanted lists already contain the replacement quantities.

Checks and availability

All 39 final combinations have cataloged LEGO element codes: catalog audit. The digital checks pass for collisions, assembly order and a single connected assembly. Replacement pieces fill the same occupied volumes as their originals.

The model has not been physically built. Fourteen support/foundation warnings remain; additional seams can affect stiffness. Seller stock, sufficient quantities and delivered prices still need checking. The GoBricks price does not apply to this LEGO version.
